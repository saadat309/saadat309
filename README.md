## About

Full-stack developer with experience across the development and delivery of web applications, from frontend architecture and backend systems to databases, deployment, and infrastructure.

The primary development stack is **JavaScript**, with experience in **React, Next.js, TanStack, Node.js, PHP, and the MERN stack**. Backend and data-layer work includes **REST APIs, MySQL, PostgreSQL, and SQLite**.

Projects have included business websites, e-commerce platforms, administrative dashboards, and custom web applications, with responsibility extending from implementation to deployment and production configuration.

Additional experience includes **AI integrations, chatbots, automation workflows, and cloud infrastructure**. Current development work is expanding into **Python and mobile applications with Flutter and Dart**.
